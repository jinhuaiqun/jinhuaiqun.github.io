# 如何写一篇博客文章 📝

写文章很简单：**在 `content/posts/` 目录下新建一个 `.md` 文件，用 Markdown 语法写内容，保存即可。**

## 第一步：新建文章

```bash
hugo new content posts/我的文章.md
```

或者直接在 `content/posts/` 下手动新建一个 `.md` 文件。

## 第二步：写文章头部（front matter）

每篇文章开头用 `---` 包裹"元信息"：

```yaml
---
title: "我的第一篇文章"
date: 2025-01-01
tags: ["生活", "随笔"]
summary: "这篇文章的简介，会显示在文章列表中"
---
```

## 第三步：写正文

```markdown
# 一级标题

## 二级标题

这是一段**加粗**文字，还有*斜体*文字。

- 列表项一
- 列表项二

1. 有序列表一
2. 有序列表二

> 这是一段引用

![图片描述](图片地址)
```

## 常用语法速查

| 语法 | 效果 |
| --- | --- |
| `#` ~ `######` | 标题（1~6 级） |
| `**文字**` | **加粗** |
| `*文字*` | *斜体* |
| `[文字](链接)` | [超链接](https://www.example.com) |
| `` `代码` `` | `行内代码` |
| ` ```代码块``` ` | 代码块（带复制按钮） |

## 数学公式（MathJax）

这个博客支持 **LaTeX 数学公式**，用 `$...$` 写行内公式，用 `$$...$$` 写独立公式：

- 行内公式：质能方程 $E = mc^2$
- 独立公式：

$$
f(x) = \int_{-\infty}^{\infty} \hat f(\xi)\,e^{2 \pi i \xi x} \,d\xi
$$

## 写完后

保存文件，刷新浏览器，新文章就出现了！🎉
